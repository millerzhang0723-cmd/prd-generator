# 单功能需求模板：信息展示页（详情/只读）

> 适用：**以只读展示为主**的页面或区域；常见为**详情页、配置预览、报告/结果只读、抽屉内详情**等。含分区标题、键值对/长文本/标签/链接/附件等展示形态，以及**少量非表单类操作**（返回、刷新、跳转、复制、下载、导出等）。  
> **编排位置**：交付稿中置于 `## 3 产品需求详述` 下，作为 `### 3.x.x …` 功能小节（**勿把本 `>` 说明块原样复制进对外 PRD**）。  
> 详情页以**只读展示**为主，模板采用四段结构：**1 原型截图 → 2 功能说明 → 3 字段说明 → 4 异常情况说明**（**不设**单独的「状态与操作关系」章节；若工具栏按钮随业务状态变化，在 **§3.3** 或各工具栏行的「注释」中约定即可）。其中「字段」含**面包屑与页头、状态角标、工具栏按钮、各分区标题、每一条展示项、内嵌列表/时间轴/Tab、页脚操作**等，不仅指业务主数据字段。  
> **默认交互**：凡会发起请求的按钮（**刷新、下载、导出、生成、复制若走接口**等），须在「字段说明」中写明 **loading 展示 + 请求中禁用**，结束后恢复，防止连续点击重复触发（与 **2.4 全局交互与展示约定**、[`references/global-ui-conventions.md`](../references/global-ui-conventions.md) 一致）。  
> **主内容加载**：详情依赖接口拉取主数据且耗时可感知时，须有 **整页/内容区 Skeleton、Spin 等**（未约定时可写「同 2.4」）。  
> **文字超长**：标题、字段值、标签等展示不全时，按 **2.4**：末尾 **「…」/「...」** + **鼠标悬停气泡**展示全文；移动端按 2.4 或本节单独约定。  
> **状态自动更新**：若页头或字段展示**会随异步任务变化的状态**（如进行中→已完成），须在「字段说明」相关行或 **§3.3** 约定 **无需用户手动刷新整页**即可变为终态（默认同 **2.4**）；仅手动刷新的详情须在本文写明。

（小节标题示例：`### 3.x.x 功能名称`；首段可写一句总述，如：「展示 xxx 的完整信息，供查看与跳转关联功能。」）

## 3 字段说明

下列对象统一填入本表：**面包屑、页标题、状态展示、工具栏各按钮、锚点/Tab、分区标题、每一条只读展示项、内嵌列表表头与操作列、附件行操作**等。  
列含义：**字段名称**为界面展示名或控件名；**字段说明**为展示含义与用户可读口径；**约束条件**含展示格式（文本/标签色/链接/代码块/图片）、空值规则、是否可复制、是否外链新开等；**示例**填示例值或示例文案；**注释**填**字段级权限与脱敏**、与原型差异、数据来源、精度与时区、**工具栏显隐与业务状态/角色**（或写「见 §3.3」）等。  
对**会触发接口的控件**，须写清：**loading 形态**、**进行中是否禁用**、失败/成功后如何恢复可点。

**撰写粒度参考**（可与表单类 PRD 同样展开到行级）：

- **分区**：一级/二级标题、分隔线；仅作导航锚点时说明锚点 id 与滚动行为。
- **键值对行**：标签文案、值对齐方式（左/右）、多行值是否默认折叠与「展开全文」。
- **枚举/状态**：标签配色、与业务状态机命名一致；进行中状态是否轮询/推送见注释。
- **数字/金额/日期**：千分位、小数位、货币符号、时区、相对时间（如「3 分钟前」）的统一口径。
- **链接**：站内路由、站外新开、`mailto`/`tel`；无权限时展示纯文本或「无权限查看」。
- **长文本/Markdown/HTML**：是否渲染富文本、XSS 安全责任边界（产品约定+研发实现）。
- **代码/JSON**：是否语法高亮、最大展示高度、复制按钮是否走剪贴板 API。
- **附件/图片**：预览（弹窗/新页）、大小/格式限制提示、下载命名规则。
- **内嵌列表**：列定义、排序、分页或「加载更多」、行操作是否与主对象状态联动。
- **信息 icon**：hover 展示口径说明、与字段值关系（避免与「约束条件」重复）。

## 4 异常情况说明

描述**详情页在数据或请求异常时的界面表现与交互**，避免仅依赖原型而未约定文案与行为。  
与第 3 节对照：加载中、失败、无数据、无权限、对象不存在、部分区块失败等。


| 场景 | 界面表现 | 文案/操作示例（可替换为实际稿） | 备注 |
| --- | --- | --- | --- |
| 主数据加载中 | 整页 Skeleton / 内容区 Spin；工具栏是否禁用 | — | 是否展示标题栏骨架 |
| 主数据加载失败 | 错误页或内容区错误占位；重试按钮 | 「加载失败，请重试」 | 是否保留上次成功缓存 |
| **数据不存在 / 已删除** | 404 或业务空态；引导回列表 | 「xxx 不存在或已删除」 | 与列表删除后返回联动 |
| **并发查看冲突**（可选） | 他人删除或撤回导致当前 ID 失效；刷新后提示 | 「数据已变更或不存在」 | 与编辑页版本号策略可统一约定 |
| 无整页查看权限 | 整页占位或跳转 | 「您暂无权限查看 xxx」 | 与路由守卫、菜单隐藏一致 |
| **部分区块加载失败** | 仅该区块错误卡片；其余正常展示 | 区块内「加载失败」+ 重试 | Tab 懒加载时是否影响切换 |
| 刷新失败 | Toast 或页内提示；是否保留旧数据 |  | 与工具栏「刷新」联动 |
| 下载/导出失败 | Toast；是否可重试 |  | 大任务异步失败的通知方式 |
| 网络超时/断网 | Toast；已展示数据是否保留 |  |  |
| （按需增行） |  |  |  |

**验收要点（测试可读，按需删改）：**

1. 入口、路由参数、直达鉴权与第 2 节一致。
2. 各展示项格式、空值占位、超长、链接行为与第 3 节一致。
3. 脱敏与字段级可见性与 3.1 一致。
4. 会发起请求的操作：loading、禁用、防重复与 2.4 一致。
5. 第 4 节各异常场景文案与交互符合约定。
6. 状态角标、工具栏显隐与 **§3.3**（或字段表注释）及业务约定一致；异步状态自动更新符合约定。
