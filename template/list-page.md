# 单功能需求模板：列表页

> 适用：表格列表 + 筛选 + 新建 + 批量操作；行内或操作列含查看/编辑/删除等。  
> **编排位置**：交付稿中置于 `## 3 产品需求详述` 下，作为 `### 3.x.x …` 功能小节（**勿把本 `>` 说明块原样复制进对外 PRD**）。  
> 结构对齐 Word 列表页范式：**1 原型截图 → 2 功能说明 → 3 字段说明 → 4 异常情况说明 → 5 状态与操作关系（流程示意图）**。其中「字段」含筛选项、按钮、列表列、翻页等，不仅指数据列。  
> **默认交互**：凡会发起请求的按钮（查询、新建/导出、行内操作、弹窗确定等），须在「字段说明」中写明 **loading 展示 + 请求中禁用**，结束后恢复，防止连续点击重复提交。  
> **默认排序**：若本小节未单独约定列表排序，默认按 **操作时间倒序**（与 **2.4 全局交互与展示约定** 一致）；业务字段名（如「更新时间」）在「列表说明」或注释中注明即可。  
> **文字超长**：列内或标题等因空间有限展示不全时，按 **2.4**：末尾 **「…」/「...」** + **鼠标悬停气泡**展示全文。  
> **状态自动更新**：若列中含**会随异步任务变化的状态**（如进行中→已完成），须在「字段说明 / 本文第 5 节」约定 **无需用户刷新整页**即可自动变为终态（默认同 **2.4**）；仅手动刷新的列表须在本文写明。

（小节标题示例：`### 3.x.x 功能名称`；首段可写一句总述，如：「xxx 的管理，列表展示所有 xxx。」）

## 5 状态与操作关系（流程示意图）

描述**列表行状态**与**操作按钮显隐、可点性**的对应关系；异常重试、自动重试、编辑互斥等规则写清。  
建议使用 **Mermaid** `flowchart`/`stateDiagram` 或贴「状态-操作」对照说明；复杂时补充文字条款（编号列表）。

```mermaid
flowchart TB
  subgraph 示例
    A[待启动] -->|启动| B[运行中]
  end
```



**文字条款示例（按需保留或改写）：**

1. 异常状态包含：……（数据源、目标库、下游服务等）
2. 出现异常时自动重试次数；连续失败达到阈值后任务置为异常
3. 异常后是否定时自动再启、间隔说明
4. 异常与用户编辑并发时：是否禁止保存、是否触发重启等
5. 特定状态下点击「确定」等按钮时的 Toast 与是否停留当前页/返回列表
